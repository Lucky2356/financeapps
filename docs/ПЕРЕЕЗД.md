# Переезд с машины

Что перестать держать на компьютере — и что с него обязательно снять, прежде чем
он будет переустановлен.

## Что уже не на компьютере

Весь проект и вся сборка живут в GitHub:

| Что                         | Где                                                        |
| --------------------------- | ---------------------------------------------------------- |
| Код, история, документация  | репозиторий                                                 |
| Проверки на каждый коммит    | `CI` — типы, линт, тесты с порогом покрытия, сборка, e2e    |
| Установщик для Windows      | `Windows Desktop Release` по тегу `v*`                      |
| APK для Android             | там же, задание `Build Android APK`                         |
| Подпись обновлений          | секрет `AUTO_UPDATE`                                        |
| Подпись APK                 | секреты `ANDROID_KEYSTORE_*` (см. `docs/ANDROID.md`)        |
| Публикация релиза и проверка| то же задание: подпись, манифест, доступность файлов        |

Выпуск версии — это поднять номер в четырёх местах, дописать CHANGELOG,
поставить тег и запушить его. Дальше ничего делать руками не нужно: сборка,
подпись, публикация и проверки идут в GitHub.

## Что нужно снять с машины до переустановки

### 1. Два ключа подписи — восстановить их невозможно

| Файл                                       | Зачем                                        |
| ------------------------------------------ | -------------------------------------------- |
| `financeapps-updater.key` (+ `.key.pub`)   | обновления на ПК; в приложениях зашит его публичный ключ `F75AC972322EB596` |
| `financeapps-release.jks` и его пароли      | подпись APK; путь указан в `src-tauri/gen/android/keystore.properties` |

Оба уже лежат (или должны лечь) в секретах GitHub, но **секрет читается только
на запись**: посмотреть его значение обратно нельзя ни через сайт, ни через
`gh`. Копия самих файлов и паролей нужна отдельно — менеджер паролей, флешка,
облако. Без них:

- потерян ключ обновлений — установленные копии на ПК перестанут обновляться, и
  починить это можно только новой установкой у каждого;
- потерян ключ APK — новую версию нельзя поставить поверх старой, придётся
  удалять приложение вместе с данными.

### 2. Данные приложения

Они лежат в браузерном хранилище внутри установленного приложения, а не в
файлах, которые видно в проводнике. Снимаются только изнутри:
**Настройки → Данные → Резервная копия → выгрузить**. Файл положить туда же,
куда ключи. На новой машине (или на телефоне) он восстанавливается тем же
экраном.

Сделать это нужно **на каждом устройстве, где велись свои записи** — синхронизации
между ними нет.

### 3. Всё остальное — уже в git

Проверить, что ничего не осталось только локально:

```bash
git status --short
git log --oneline origin/main..HEAD
```

Пусто в обеих командах — на машине нет ничего своего, кроме ключей и данных выше.

## Как работать дальше без этой машины

- **Выпустить версию** — тег `vX.Y.Z`, всё остальное делает GitHub.
- **Поправить код** — GitHub Codespaces или Claude Code на claude.ai/code: оба
  работают прямо с репозиторием, сборка идёт на стороне GitHub.
- **Собрать локально** (если захочется) — всё по-прежнему работает: `npm ci`,
  `npm run tauri:build`, `npm run android:build`. Для APK понадобится вернуть
  `keystore.properties` с путём к сохранённому `.jks`.

Единственное, что нельзя сделать без своей машины, — проверить приложение
глазами на живой Windows-сборке. Автотесты (`CI`) проверяют логику и статическую
оболочку, но не установленное приложение.
